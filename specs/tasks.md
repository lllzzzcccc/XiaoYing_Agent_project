# 内容任务规划 Agent 实施任务

- 阶段：Plan
- 上游：`specs/spec.md`、`specs/plan.md`、`specs/contracts.md`
- 本文仅拆分后续工作，不包含实现或测试代码。

## 1. 执行规则

- 每个行为任务遵循 **RED → GREEN → REFACTOR → VERIFY**：先写会失败的契约测试，再写最小实现，随后重构并运行相关验证。
- 先执行 P0 任务；T016 为 P1 加分项，不阻塞核心交付。
- 测试必须验证公开行为和实际状态，不得只断言函数被调用或复制预设日志。
- Faux Provider 用于确定性 Agent 集成测试；真实模型运行单独形成证据，不用 Mock 代替。
- 每个任务完成后更新追踪状态和实际结果；失败与未完成项必须保留，不得改写成通过。
- 本阶段所有复选框保持未完成；后续实施时按实际完成情况勾选。
