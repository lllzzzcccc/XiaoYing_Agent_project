# AI 辅助使用说明

## 使用范围

本项目使用 Kimi Code CLI 辅助完成：

- 阅读笔试 HTML，整理 SDD 规格、技术方案、工具/状态契约和任务拆分。
- 初始化 Node.js/TypeScript/Pi 项目，编写领域逻辑、工具、Agent、CLI、本地存储和续跑。
- 编写并执行契约、集成、跨进程、证据和文档测试。
- 生成实际离线输入、输出、Trace、保存方案及本仓库文档。
- 按任务进行 Git 提交并维护 `specs/acceptance.md`。

## 个人贡献与修改

用户提供原始笔试题、技术栈限制、业务规则澄清和阶段目标，确认 CLI、Pi 官方包、费用/时间口径、JSON 输入、防重复和本地保存要求，并授权测试先行实施及任务提交。

需求、设计与实现决策由 AI 按用户确认的规格执行；用户没有逐行提供实现代码或声明人工逐行修改。真实模型凭据、Provider/Model 配置和远程仓库权限仍需用户提供，AI 未虚构这些外部条件。

## 验证

AI 按每项任务先写失败检查，再实现并运行相关验证，最后运行全量测试和检查变更。当前验证包括干净安装、构建、65 项测试、6 组离线实际材料、2 条 DeepSeek 真实路径、独立保存读取和跨进程续跑。

个人后续评审应重点核对真实 Provider 路径、模型动作与工具观察是否匹配，以及评估文档是否如实区分真实和 Mock 证据。
